## Remaining feature boundaries

do not become complete live incident signals, a complete migration feed or
automatic maintenance admission. Default automatic investigations, runways,
change polling, proposals and notifications remain disabled. Empty SLO
configuration cannot establish any real business SLO; an explicitly configured
application must supply its actual eligible/bad counters. Backend cancellation
and optional agent/MCP protocols remain withheld by this integration; a query
probe succeeding is not an executed-action proof. Broader versions, HA/failover,
all incident families and long-term credential/production-SLO endurance remain
separate validation work.

## Full-suite findings: maintenance retention and migration fixture

The broad regression found `TestRetentionRules_CoverEveryTimeSeriesTable` failing
because `sre_maintenance_proposals` lacked a declared purge rule or exemption.
Independent lifecycle review found more than a missing declaration: aging a
concluded investigation could cascade an active/unresolved maintenance ledger;
ordinary action retention could remove its rollback log or related audit links.
The correction must preserve active/unresolved work and age completed maintenance
from its latest update, while eventually cascading expired/finalized records with
the investigation. A map entry alone is insufficient.

Maintenance retention must also respect topology. Direct SQL references cannot
protect queue/action records in a different monitored database from the SRE
control store. The bounded correction will refuse only the typed maintenance
bridge in that split-store topology, while retaining ordinary SRE observations
and existing actions. Distributed retention holds remain unsupported. The
selected Lakebase/App topology is colocated. The full inventory completed unchanged. Corrections continue in the dev.5
revision, with the failed dev.4 invocation preserved.

A separate schema migration test omitted the new child table from its explicit
teardown order, so the foreign key correctly refused dropping its parent. The
minimal fixture correction includes that child before the parent, preserving
integrity. Its ignored overlay passed focused migration tests (2.622s) with race,
coverage and both tags. No CASCADE bypass was introduced.
