## Remaining limits and promotion gates

- **Provider delivery:** selected-resource plans/logs/DDL remain unverified;
  native delivery, normalization and masking cannot be promoted from empty
  reads. No broad account/PII grant or private provider API was used to bypass it.
- **Historical consumers:** the plan cache and explicit scoped optimizer are
  wired. Automatic historical logs/ASH/DDL integration into RCA, migration and
  SRE, event-window SLOs and provider-plan regression comparison remain incomplete.
- **Maintenance:** eight executor contracts have native acceptance; this does
  not constitute an SRE-to-maintenance proposal/execution bridge. App trust stays
  observation-only. Cancellation and other unavailable families remain refused.
- **Provider restrictions:** hint hooks are inactive/refused, HypoPG absent and
  pgAudit installation refused for the tested role. Historical telemetry cannot
  activate those features or provide live host/space admission. OAuth through
  the built-in transaction pooler remains unsupported.
- **Breadth:** deep new native acceptance is PG18 with the selected user and App
  identities. Earlier version surveys, credential endurance and resume evidence
  remain distinct; this run does not newly certify every datatype/version,
  incident family, HA/failover, App hour-boundary refresh or production workload.
- **Rollback:** prior source snapshots and the previous local executable are
  retained. New history/policy schema migrations require a compatibility review
  before reverting to an older binary; no destructive schema downgrade or
  universal old-binary rollback has been validated.

The task-owned local PostgreSQL/build containers are stopped after acceptance;
