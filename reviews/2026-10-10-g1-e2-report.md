### Design

- **Chain.** Each audit table write appends a link to `sage.audit_chain_link` from a deferred
  constraint trigger, so links are made at commit: the advisory lock that orders writers is the
  last lock a transaction takes (no new deadlocks), a rollback takes no position (no gaps), and
  chain order is commit order (the SIEM cursor). A link hashes `prev|seq|op|row_id|v|sealed_hash|state`.
  Inserted rows carry `chain_seq`, `chain_prev_hash`, `chain_hash`. Sealed columns are what was
  done; outcome columns updated later are chained as `U` links; deletes are `D` links; TRUNCATE
  is a `T` link. Chained: `action_log`, `auth_audit`, `config_audit`, `guard_pgaudit_events`, and
  `guard_query_audit` once core creates it. The verifier reports gaps, reordering, edited links,
  edited sealed columns, state changed behind the chain, silent deletes and rows written with
  triggers bypassed.
- **OAuth.** go-oidc verifies signature (asymmetric algorithms only), issuer, `exp`/`nbf`; pg_sage
  checks audience. Every database is its own resource, `<resource>/databases/<name>`, served at that
  path: a token for A is 401 at B, a foreign `aud` is 401 everywhere (G1-03). The server-wide
  resource reaches only databases whose resources the same `aud` names. `pg_sage:read` is
  required, `pg_sage:propose` optional, approve never. Identity `(iss, act.sub)` under RFC 8693
  delegation (else `sub`) resolves via `sage.guard_identity_bindings`; the principal is loaded from
  core's `agentguard.Store` and bound as `agentguard.Identity` (task claim, `on_behalf_of`,
  databases) with `mcp.Principal.PrincipalID`.
- **SIEM.** Per-sink cursor over the link table; sinks run on their own goroutines, on the fleet
  leader, cursor writes fenced by the lease epoch; a failing sink holds its cursor (backpressure in
  the database), retries with exponential backoff, and loses nothing. Events carry the link hash.
  Secret config values are redacted.

1. SIEM events carried secret configuration values in the raw row copy (`unmapped.pg_sage.row`); now redacted.

3. `sage.config_audit` is created after the migration list, so its chain would have installed one restart late; the chain install is now Bootstrap's last step.
4. `config_audit.id` is int4: verifier parameters overflowed; cast to bigint.

## Suggested CHANGELOG bullets
- Audit trail is now tamper-evident: action, sign-in, config and pgaudit records are hash-chained, verified daily, and a broken trail raises a critical finding.
- SIEM export: every audit event as OCSF over HTTP, syslog (TCP/UDP/TLS) or OTLP, at least once, without slowing pg_sage.
- MCP accepts OAuth 2.1 access tokens from configured issuers, bound to one database by audience.
- Evidence packs: download a signed or hashed bundle for an action or a time window.
- Agent principals can be declared in a versioned file with plan and apply.
