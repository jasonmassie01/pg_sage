# Self-configuration class of every configuration key (roadmap phase 3).
#
#   safety_critical      never derived: trust and approval, emergency and action
#                        authority, verification that feeds trust, credentials,
#                        endpoints, LLM provider/keys, the self_config switch
#                        itself, anything whose change widens what pg_sage may do.
#   operator_preference  never derived: what the operator declares (notification
#                        routes and windows, maintenance windows, declared
#                        capacities, feature switches, fleet topology, audit
#                        retention, the fleet LLM budget cap).
#   derivable            pg_sage may derive a value per database from evidence,
#                        within bounds that never widen authority or spend,
#                        when the operator leaves the key unset. Only keys with a
#                        rule in internal/selfconfig are derived today.
#
# Format: "<class> <key>", one per line. Every key of Config (and every
# databases[] field) must appear exactly once: a new key fails
# TestEveryConfigKeyIsClassified until it is classified here.
